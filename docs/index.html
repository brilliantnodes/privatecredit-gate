A credit facility whose covenants test themselves.

In private credit, every quarter someone at the lender reads the borrower's compliance report and keys the numbers in by hand. Errors, delays and arguments over what the report says all happen at that step. Here, GenLayer validators each read the borrower's own published report, copy four figures into a fixed form, and plain code applies the facility agreement. Money moves only on figures every accepting validator copied exactly the same.

  1. Offer and accept. The lender deposits the commitment; every term is frozen, including one report address per period. The borrower accepts by funding a debt-service reserve.
  2. Test. After each period end anyone runs the covenant test. Each validator reads the page and copies LTM EBITDA, LTM net finance costs, total debt and cash, exactly as printed.
  3. Decide in code. Integers only: leverage, interest cover and minimum cash by cross-multiplication, the margin band, the draw stop, cures, waivers and events of default.
  4. Set dates. Margins, deadlines and default interest fall on fixed dates, never on who sends a transaction first.

          The rules, in brief

          • Agreement is exact on everything stored: the outcome kind, the reason code of a no-reading, and all four figures. Only a READ is final; the first READ in a period's window is its official reading.
          • The model copies; code decides. Company, period end to the minute, currency, LTM labels and scales are checked in code. Ambiguous figures (12.450, 6,28, a decimal comma, other time zones) are refused, never guessed.
          • Finance costs take their sign from the line label, classified in code (reports print expenses in brackets).
          • Draw stop: from each period end until that period has a compliant, cured or waived reading. The period-0 reading is the condition precedent.
          • Margin from the leverage band at the window close; a missing report means the top band.
          • Equity cure before the cure deadline: at most two, never consecutive; only the principal it prepays counts against net debt; it fixes leverage only.
          • Events of default on fixed dates: E1 uncured breach, E2 missing report, E3 unpaid interest (remedied by payment), E4 principal unpaid after maturity. The lender may waive E1 to E3 and accelerate in default.
          • Waterfall: fees, interest, then principal that is due or that the borrower chooses to prepay; any excess comes back. A refused payment always comes back.
